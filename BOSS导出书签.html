BOSS 岗位一键导出

BOSS 会拦截「另开的自动化浏览器」。所以这里改成在你自己的 Chrome 里跑：你登录、搜好岗位 → 点一下书签 → 它自动往下滚、把所有岗位加载出来 → 直接导出 CSV → 丢进工具清洗筛选。全程没有自动化浏览器，BOSS 不拦。

第 1 步：把下面的按钮拖到书签栏

先按 Ctrl + Shift + B 显示书签栏，然后用鼠标把下面这个蓝色按钮拖到书签栏上，松手即可。

📥 BOSS岗位导出（自动翻页）

拖不动？右键书签栏 →「添加网页 / 添加书签」→ 名称随便填 → 网址粘贴下面这行 → 保存。

第 2 步：去 BOSS 搜岗位

在你自己的 Chrome 里正常打开 BOSS 直聘，搜索目标岗位（如「Python 深圳」），等职位列表出来。

第 3 步：点一下书签栏的「📥 BOSS岗位导出」

右下角会出现一个小蓝条，显示「正在加载岗位… 已收集 N 条」。它会自动往下滚、一直加载到没有新岗位为止（岗位多就久一点，期间别动页面）。

结束后自动下载 boss_数字.csv（含 公司/岗位/城市/薪资/经验/学历/描述/链接/HR活跃）。

第 4 步：导入工具

打开工具页 http://localhost:8090 → 点「上传 CSV」→ 选刚下载的文件 → 清洗 + 按 城市/薪资/技能/HR活跃度 筛选。
